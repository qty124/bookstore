# 东软汇达智慧图书购物网站

## 项目简介
本项目是一个基于HTML5 + CSS3 + JavaScript的智慧图书购物网站，包含完整的用户注册登录、商品浏览、购物车、订单管理等功能。

## 目录结构
```
大作业/
├── index.html              # 首页入口
├── pages/
│   ├── index.html          # 首页（轮播图、搜索、分类、商品列表）
│   ├── login.html          # 登录页面（含验证码）
│   ├── register.html       # 注册页面（含表单验证）
│   ├── product.html       # 商品详情页
│   ├── cart.html          # 购物车页面
│   ├── checkout.html       # 订单确认页面
│   ├── order-detail.html   # 订单详情页面
│   └── user.html          # 个人中心
├── css/
│   └── style.css          # 公共样式
├── js/
│   └── main.js            # 核心JS（商品数据、购物车逻辑）
└── images/
    ├── banner1.svg ~ banner3.svg   # 轮播图
    └── product1.svg ~ product8.svg # 商品图
```

## 主要功能

### 1. 首页模块
- 轮播图自动播放（3秒切换）
- 搜索框搜索商品
- 分类筛选（全部/编程/计算机基础/Web开发/前端框架）
- 商品列表展示

### 2. 用户模块
- **注册**：用户名、邮箱、手机号、密码表单验证
- **登录**：验证码校验、密码校验
- **个人中心**：订单统计、订单列表、账户设置

### 3. 商品模块
- 商品详情展示（名称、价格、作者、出版社、ISBN、库存）
- 商品数量选择
- 加入购物车功能

### 4. 购物车模块
- 商品数量增减
- 删除商品
- 全选功能
- 小计计算

### 5. 订单模块
- 地址管理（添加新地址）
- 配送方式选择
- 支付方式选择
- 订单提交
- 订单号生成

## 技术栈
- HTML5：语义化标签、表单元素
- CSS3：Flexbox布局、Grid布局、渐变背景、圆角、阴影、过渡动画
- JavaScript：DOM操作、事件处理
- localStorage：数据持久化
- AJAX：模拟异步请求（Promise + setTimeout）
- JSON：数据格式

## 运行方式
1. 直接用浏览器打开 `index.html` 即可运行
2. 无需安装任何依赖或启动服务器
