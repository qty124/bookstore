一、系统功能结构图

本系统采用B/S架构，前端使用HTML5 + CSS3 + JavaScript实现，后端使用本地存储模拟数据持久化。系统功能结构如下：

  • 首页模块：轮播图、搜索框、分类筛选、商品列表展示
  • 用户模块：注册（表单验证）、登录（验证码+密码校验）、个人中心（订单管理、账户设置）
  • 商品模块：商品详情（图片、价格、库存、作者信息）、商品分类浏览
  • 购物车模块：数量修改、商品删除、全选结算
  • 订单模块：地址管理、订单确认、支付流程、订单查询

二、技术栈说明

2.1 前端技术

  • HTML5：语义化标签（header、nav、section、article、footer）、表单元素、localStorage API
  • CSS3：Flexbox布局、Grid布局、渐变背景、圆角、阴影、过渡动画、响应式设计
  • JavaScript：DOM操作、事件处理、localStorage数据持久化、轮播图自动播放
  • AJAX：模拟Ajax请求（Promise + setTimeout实现异步数据加载）
  • JSON：商品数据、用户数据、购物车数据均以JSON格式存储和传输

2.2 数据存储方案

  • localStorage：用户注册信息（users）、当前登录用户（currentUser）、购物车数据（cart_[用户名]）、订单数据（orders_[用户名]）
  • 采用JSON字符串格式存储，支持数据的增删改查操作

4.2 购物车数据管理（localStorage + JSON）

// 加入购物车 function addToCart(productId) { const user = JSON.parse(localStorage.getItem('currentUser')); if (!user) { alert('请先登录'); return; } let cart = JSON.parse(localStorage.getItem('cart_' + user.username) || '[]'); const idx = cart.findIndex(i => i.id === productId); if (idx >= 0) { cart[idx].qty += 1; // 已存在则数量+1 } else { cart.push({ id: productId, qty: 1 }); // 新增商品 } localStorage.setItem('cart_' + user.username, JSON.stringify(cart)); alert('已加入购物车！'); }

五、实验总结

5.1 解决的问题

  • 表单验证：实现了用户名、密码、邮箱、手机号、验证码的多重校验，使用正则表达式进行格式验证
  • 数据持久化：使用localStorage实现用户数据、购物车、订单的本地存储，支持刷新后数据不丢失
  • 轮播图：使用CSS Transform实现平滑切换动画，定时器实现自动播放
  • 跨页面数据传递：使用URL参数（?id=1）实现商品详情页与首页之间的数据传递

5.2 未来改进方向

  • 接入真实后端API，实现用户数据的服务器端存储
  • 使用Vue.js/React等框架重构，提升开发效率
  • 添加商品搜索、排序、分类筛选等高级功能
  • 实现微信/支付宝支付接口
  • 添加商品评价、收藏、推荐等功能
